# زبان طراحی

الهام: **Liquid Glass** (iOS 26) + تلگرام. آرام، تمیز، خوانا برای سالمندان.

## Liquid Glass — سه لایه (`ui/components/Glass.kt`)
1. **پس‌زمینه** `MeshBackground`: لکه‌های رنگی نرم (نعنایی، آبی آسمانی، یاسی، هلویی / در تم تیره: سبز تیره، نیلی، بنفش، فیروزه‌ای). بدون این، شیشه خاکستری و مرده دیده می‌شود.
2. **محتوا** `Modifier.glass()`: کارت نیمه‌شفاف + لبه‌ی بالایی روشن که محو می‌شود + سایه‌ی نرم. (بدون blur واقعی؛ ارزان است.)
3. **کروم** `Modifier.liquidBar()`: نوار پایین شناور، نوار وضعیت و هدر ویرایشگر — **blur واقعی** پشت‌زمینه با کتابخانه‌ی Haze (اندروید ۱۲+؛ پایین‌تر رنگ ساده). نشانگر تب انتخاب‌شده یک «قطره»‌ی شیشه‌ای است که با فنر جابه‌جا می‌شود.

قاعده (از ui-ux-pro-max): شیشه فقط برای ناوبری و کنترل‌ها؛ محتوا لایه‌ی جدا؛ رنگ کم و هدفمند.

## اصول
1. **امروز محور**: صفحه‌ی اول جواب «الان چی باید بخورم؟» است، نه لیست داروها.
2. **Large title** بالای هر صفحه (۳۲sp، Bold) + زیرعنوان خاکستری (تاریخ شمسی).
3. **Grouped inset lists**: کارت‌های گرد (۲۰dp) روی پس‌زمینه‌ی خاکستری روشن، جداکننده‌ی نازک بین ردیف‌ها.
4. **شناخت دارو از ظاهر**: هر دارو آیکون شکل+رنگ خودش را دارد (قرص گرد، کپسول دو رنگ، شربت، قطره، اسپری، آمپول).
5. **یک لمس**: تیک دایره‌ای کنار هر وعده؛ با انیمیشن فنری + لرزش کوتاه (haptic).
6. تم روشن و تیره بر اساس سیستم.

## صفحات
- **امروز**: عنوان + تاریخ شمسی → کارت حلقه‌ی پیشرفت (x از y) → کارت هشدار دسترسی‌ها (اگر لازم) → بخش‌ها بر اساس ساعت → بخش «در صورت نیاز».
- **داروها**: لیست گروه‌بندی‌شده با خلاصه‌ی برنامه («شنبه‌ها · ۲۲:۰۰ · ۲ عدد») و نشان موجودی؛ دکمه‌ی + بالا.
- **تاریخچه**: نمودار ۷ روز اخیر (درصد پایبندی) + لاگ‌ها به تفکیک روز.
- **ویرایشگر**: یک فرم گروه‌بندی‌شده (مثل ساخت آلارم iOS) در صفحه‌ی کامل.
